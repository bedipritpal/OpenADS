Also added SHA256/384/512, HMAC-SHA384/512 and OADS_RANDOMBYTES.
Existing HMAC-SHA256/base64/hex/string/UTC surface retained.

Excluded: MD5File/file/directory/DBF/RDD/config/environment/process/shell/network/socket functions; dynamic loaders/macros; sleeps; global runtime setters; arbitrary memory/pointer operations and dedicated callback-evaluation helpers (AEVAL/HB_HEVAL); array scan functions retain their normal Harbour semantics. Existing core VM capabilities are not a security sandbox.

MD5 is weak: checksums only, not proof of identity. Blowfish ECB/CFB is legacy, unauthenticated encryption, not a signature or a replacement for TLS/HMAC. Use unique unpredictable CFB seeds; Harbour transforms the seed into its internal IV.

OADS_RANDOMBYTES(n): integer1..1024, binary result; NIL for invalid input or entropy failure. mbedTLS entropy + CTR_DRBG, independently seeded per call; no weak fallback.
